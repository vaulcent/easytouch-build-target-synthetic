# Easytouch synthetic Build target

This repository is disposable, fabricated material only. It exists so the Easytouch AI Lab
Build/Preview control plane has a real (but synthetic) customer-style GitHub repository to
integrate against for D1 — it is not a real customer, contains no real customer code or data,
and may be reset or deleted at any time.

`synthetic_build_target_app` is a minimal Frappe custom app, structured the same way a real
customer app would be, so `Requirement`-driven changes have something realistic to patch.

Default branch: `main`. Change branches follow `change/<change-id>`.
